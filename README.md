# React Quiz App 🧠⚡

![React Quiz App Banner](./public/banner.png)

A modern and interactive quiz application built with **React**.  
This project focuses on clean state management, component composition, and real-world React best practices.

Users can answer timed questions, skip questions, and receive a detailed performance summary at the end of the quiz.

## 🧠 React Concepts Practiced

- State management using `useState`
- Derived state (computed values instead of redundant state)
- Conditional rendering
- Component composition and reusability
- Props and unidirectional data flow
- Performance optimization with `useCallback`
- Timed side effects using `setTimeout`
- Dynamic class assignment
- Rendering lists with keys
- Clean project structure and Git best practices
